# Changelog

All notable changes to KRYTH will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.8] - 2024-01-XX

### Added
- Initial public release of KRYTH Autonomous AI Coding Agent
- Core REPL interface with prompt toolkit
- OpenAI-compatible API support
- Multi-model routing (GPT-4, Claude, Gemini, etc.)
- Comprehensive tool library for code generation, debugging, and deployment
- Session persistence and resume functionality
- Permission profiles for different autonomy levels
- Bridge mode for browser-based authentication
- Rich terminal UI with real-time updates
- Extensive configuration options via TUI
- Memory layers for project and user context
- Git integration for version control
- Subagent execution for complex tasks
- Planning and task graph capabilities
- Code critique and review tools
- Search and retrieval across codebases
- File operations with safety checks
- Shell command execution with approval workflows
- Debug logging and diagnostics
- Web UI support (separate deployment)
- Comprehensive documentation
- PyPI package distribution

### Technical
- Python 3.10+ support
- Type hints throughout codebase
- Modular architecture with plugin system
- Async/await for concurrent operations
- Comprehensive test suite
- Pre-commit hooks for code quality
- Docker containerization support
- CI/CD via GitHub Actions
