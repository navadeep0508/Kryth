## What is KRYTH?

KRYTH is an autonomous AI coding agent that builds, debugs, and deploys entire applications with minimal human intervention. It's a full-stack development partner that integrates directly into your terminal workflow.

### Key Features

- **Autonomous Code Generation**: Generate complete applications from a single prompt
- **Intelligent Debugging**: Auto-detect and fix bugs before they reach production
- **Project Scaffolding**: One-command project creation with industry-standard templates
- **Continuous Refactoring**: Code quality analysis and performance optimization
- **Multi-Model Support**: Works with GPT-4, Claude, Gemini, and local models
- **Session Persistence**: Resume interrupted work seamlessly
- **Permission Profiles**: Control autonomy levels from safe to fully autonomous
- **Bridge Mode**: Use browser sessions instead of API keys
- **Rich Terminal UI**: Beautiful, informative interface with real-time updates

## Getting Started

### Installation

```bash
pip install kryth
```

### Quick Start

```bash
# Set your API key
export OPENAI_API_KEY=your-key-here

# Start KRYTH
kryth
```

### Example Usage

```
kryth> Create a Next.js app with authentication and a dashboard
```
